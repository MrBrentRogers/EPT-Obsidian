## Ancient N'lǘssa (Dragon Warrior)
Ancient  
M/A  
Tongue of the Dragon Warriors and hence important to the worship of Vimúhla; written in a Llyáni-derived script – because of which earlier scholars thought these 2 languages to be more closely related.
